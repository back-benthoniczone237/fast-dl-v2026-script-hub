* Storage Space: At least 50 MB of free space.
* Internet Connection: Active connection to fetch game files.
* Permissions: Administrative access to allow the program to update folders.

## ⚙️ How to Install and Run

The software does not require a complex installation wizard. Use these steps to launch it:

1. Locate the file you saved in the previous step.
2. Double-click the file icon.
3. If a Windows security window appears, select "More info" and then click "Run anyway."
4. The tool will open a small window.
5. Wait for the initial loading bar to reach full status.

Once the window appears, the utility stays active in the background. You can minimize it while you play.

## 🕹️ Using the Utility

The interface shows a list of available helper scripts and game content. 

* Select a script from the dropdown menu.
* Click the "Apply" button to link that asset to your game.
* Use the "Refresh" button if your download speed drops.
* The "Web Access" tab provides links to official community forums and update patch notes.

The program creates a backup of your current game configuration file the first time you run it. You find this backup in the "Backups" folder inside the program directory. If you experience errors, you can replace your current game files with these backup copies.

## 🛡️ Troubleshooting Common Issues

Most users do not face errors, but check these points if the app stops:

* Administrator Mode: Right-click the program icon and select "Run as administrator." This fixes most permission errors.
* Firewall settings: Some security software blocks the downloader. Add the program to your list of approved applications in your antivirus settings.
* Connection status: If the download progress stays at zero, restart your router or check your site access.
* File Path: Do not place this software inside your actual game root folder. Keep it in a separate directory like "Documents" or "Desktop."

If you need to remove the software, delete the folder containing the .exe file. This action removes the helper scripts from your system completely. Because the app does not store persistent data in your Windows registry, cleaning it remains simple.

## 📈 Updating the Tool

The utility checks for new versions every time you start it. If an update exists, a prompt appears showing the version number. Click "Yes" to start the auto-update process. The app restarts itself once it finishes the file swap. You keep all your saved settings during this update process.
